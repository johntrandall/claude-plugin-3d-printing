# Refresh Procedure for 3d-model-publishing

## On cadence (quarterly)

1. Spot-check each site's upload flow still matches section 4 of SKILL.md (open the site's
   create/upload page; no login is needed to see whether the entry point moved):
   - printables.com: "+ Create" button present? STEP still accepted?
   - makerworld.com: "Upload" then "3D Model" path unchanged? 3MF-profile emphasis still true?
   - thingiverse.com: still STL-only? Still alive?
2. Re-check the site table in section 4.5: has any site changed its audience, rules or
   licence options, or shut down?
3. Check whether any new major model site deserves a row (Thangs, MyMiniFactory and Cults3D
   are already listed). Add one only if it has real repair-part or functional-print traffic.

## Verification checklist

- [ ] Upload flow notes match current site UIs
- [ ] Site table matches reality
- [ ] Frontmatter `last_refreshed_at` updated
